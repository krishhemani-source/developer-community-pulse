  • Counting and trend calculation

Deliberately never built: auto-created roadmap tickets · auto-replies in communities · a “what to build next” decision. The system measures and explains; Sumit decides.

Reading this map

  • Dark steps use Gemini Flash (@google/genai, server-side only). Every other step is plain, testable code.
  • Violet is brand or action only. In the product, orange = rising, teal = falling.
  • Stack: Next.js App Router + TypeScript strict · Tailwind + shadcn/ui · Recharts · Neon serverless Postgres · Gemini Flash · Resend · Vercel + Cron · zod · vitest (52 tests).
  • Success metrics: 0 min collection (was 90) · under 10 min to read · every pain point has a trend number · 100% of claims link to a source thread.
